# 知径

岗位方向学习路径 · 按天打卡。支持 **桌面安装版**（推荐）与本地网页版。

## 桌面版（推荐，无需浏览器）

1. 安装依赖并打包（开发者）：

```bash
npm install
npm run dist
```

2. 安装程序输出在：

```
release/知径-Setup-1.0.0.exe
```

3. 用户双击安装后，从桌面或开始菜单打开 **「知径」** 即可，无需开浏览器、无需 Python。

开发调试：

```bash
npm start
```

## 网页版（可选）

双击 `启动本地服务.bat`，浏览器打开 `http://localhost:3000/index.html`。需本机有 Python。

## 新人说明

- **路径**：一条按天的学习计划（如「产品经理 30 天入门」）
- **今天**：打卡主页
- **知识库 / 术语库**：阅读与名词速查
- **智能功能**：可选，需配置 DeepSeek 等密钥（见应用内「如何配置 API」）
