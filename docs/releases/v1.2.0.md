# 知径 v1.2.0

这是一次围绕“课包真正可学”和“每天更容易完成”的大版本更新。

## 本次更新

- 建立统一课包质量契约，逐日检查来源、引用、正文、练习和任务—资料关系。
- 改为三天微批次生成并保存检查点，中断、刷新或关闭后可以继续补全。
- 按周复用资料候选池，减少单 DeepSeek Key 下的重复搜索和等待。
- 只修复失败字段或问题 Day，不再因局部问题重生成整包。
- GitHub 资源优先显示 README 标题、文件标题或仓库描述，标题更通俗。
- 重构“今天”页，按任务、资料、练习、复盘、打卡组织学习主线。
- 费曼复述和笔记改为标签页，桌面双栏与移动端布局同步优化。
- 九步使用指南已适配新的“今天”页和复盘区域。
- Electron 升级到 43.4.0，并完成 0 漏洞依赖审计。

完整变更见 [CHANGELOG.md](https://github.com/wterenwang/zhijing/blob/main/CHANGELOG.md)。

## 下载

- Windows x64：`Zhijing-Setup-1.2.0.exe`
- macOS Apple Silicon：`Zhijing-1.2.0-mac-arm64.dmg`
- macOS 免安装压缩包：`Zhijing-1.2.0-mac-arm64.zip`

## 安装提示

Windows 使用安装向导即可完成安装。

macOS 版本未做 Apple 开发者签名，仅支持 Apple Silicon / arm64。若系统阻止打开，请先在访达中右键应用并选择“打开”。仍提示损坏时执行：

```bash
xattr -cr "/Applications/知径.app"
```

## 使用前须知

- 默认“产品经理 30 天入门”是展示路径，正式学习建议新建专属路径。
- 生成课包、AI 点评和联网检索需要用户自己的 DeepSeek API Key。
- API Key 与学习数据保存在本机；请勿在公开 Issue 或日志中提交密钥。
- 当前不提供云端账号同步。
