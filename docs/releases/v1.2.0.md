# 🎉 知径 v1.2.0：更完整的智能课包，更清晰的每日学习

这次更新围绕两件事展开：

> **让智能生成的课包真正能学，也让每天的学习更容易完成。**

## 🌟 你会感受到的变化

### 📚 每一天的内容更完整

知径会让今日任务、推荐资料、学习内容和练习互相对应。资料不再只是附在页面上的链接，而是会真正帮助你完成当天的任务。

### 🔎 推荐资料更好懂

资源标题会尽量显示成通俗的内容名称。GitHub 项目和文件不再只显示难懂的仓库名、路径或机械文件名。

### ⚡ 专属路径生成更快

相近主题会复用已经找到的资料，减少重复搜索。使用同一个 DeepSeek Key 生成较长路径时，等待时间更少。

### 💾 中断后可以继续

如果生成时刷新页面、关闭应用或主动停止，不需要从头再来。再次打开后，可以继续补全尚未完成的部分。

### 🩹 哪里有问题，就修哪里

某一天的内容没有达到要求时，知径会优先修复相关部分，不再轻易重做整个课包。

### 🧭 “今天”页更清晰

新的页面按照以下顺序组织学习：

> **今日任务 → 推荐资料 → 每日练习 → 复述与笔记 → 完成打卡**

学习进度和日历放在侧边，今天做到哪里一眼就能看见。

### ✍️ 复盘与记录更顺手

费曼复述和笔记改为标签切换。完成练习后，可以直接用自己的话复述并记录重点。

### 🐾 使用指南同步更新

九步使用指南已经适配新的页面布局，会带你认识任务、资料、练习、复盘和打卡流程。

## 🤖 使用前请配置 DeepSeek

智能生成是知径的核心能力。生成专属路径、搜索学习资料、查看练习点评和资讯解读，都需要你自己的 DeepSeek API Key。

- 没有配置密钥时，可以先浏览“产品经理 30 天入门”展示路径。
- 配置密钥后，才能生成和使用自己的完整学习路径。
- DeepSeek 可能按实际用量收费，请留意账户余额和计费规则。
- API Key 与学习数据保存在你的电脑上，请不要在截图、Issue 或日志中公开密钥。

## 📥 下载

- **Windows x64**：`Zhijing-Setup-1.2.0.exe`
- **macOS Apple 芯片**：`Zhijing-1.2.0-mac-arm64.dmg`
- **macOS 免安装压缩包**：`Zhijing-1.2.0-mac-arm64.zip`

Windows 用户运行安装程序，按照提示安装即可。

## 🍎 macOS 安装提示

当前版本仅支持 Apple Silicon（M1 / M2 / M3 / M4 等），暂不支持 Intel Mac。

安装包尚未进行 Apple 开发者签名。如果系统阻止打开，请先右键知径并选择“打开”。仍提示损坏时，在终端执行：

```bash
xattr -cr "/Applications/知径.app"
```

## 🚀 第一次使用

1. 安装并打开知径。
2. 进入“配置 API / 开启智能功能”。
3. 填入自己的 DeepSeek API Key。
4. 新建学习路径，填写行业、岗位、目标和周期。
5. 从“今天”页开始完成第一天学习。

## 🔐 数据说明

- 学习进度和 API Key 保存在本机。
- 当前没有云端账号同步。
- 可以使用应用内的“备份进度 / 恢复备份”迁移学习数据。
- 提交问题反馈前，请确认截图和日志中没有密钥或个人信息。
