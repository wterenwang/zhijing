# 知径 v1.2.1：可靠性与首次使用体验修复

本版本优先修复首次使用、生成恢复和每日学习闭环。

## 发布状态

- Windows x64 安装包可直接下载和安装。当前尚未配置 Authenticode 代码签名，Windows 可能显示“未知发布者”；请只从本仓库 Release 下载并核对下方 SHA-256。
- macOS Universal 的代码与打包配置已经就绪，但正式 DMG / ZIP 只有在 Developer ID 签名、Apple 公证、Gatekeeper 和双架构检查全部通过后才会上传。发布页没有对应文件时，请不要使用终端绕过系统限制。
- 仓库另行保留文件名带 `UNSIGNED-INTERNAL` 的未签名 Universal 内部包；该包不上传 Release，只用于开发留档，不能作为正式安装方案。

## 主要变化

- macOS 正式包改为 Apple Silicon 与 Intel 通用架构，并在发布前强制验证 Developer ID 签名、Apple 公证票据和 Gatekeeper。
- 质量状态不再显示无依据的精确百分比，改为展示已通过检查、未通过原因、学习影响和下一步。
- 自动修复没有产生变化时停止重复；可以继续使用当前内容、重新生成问题部分或重新生成整个课包。
- 认证、余额、网络和超时故障会分别提示，并保留已生成结果供稍后继续。
- 今日任务清单支持勾选、取消和本地持久化；状态按项目、实际日期和任务内容隔离。
- 长题目、自检要点和参考内容不再在生成归一化阶段被硬截断。
- 生成诊断记录等待、生成、修复、重试、失败类型和恢复结果，并对密钥脱敏。
- 每日任务复用现有日课和练习反馈，提供“怎么做、做成什么样、我做得怎么样”三段式引导。

## 验证

- 112 项工作流与回归测试通过。
- 知识库前端 TypeScript / Vite 正式构建通过。
- Windows Electron 安装包构建与发布前隐私审计通过。
- 浏览器验证覆盖首次进入、创建路径、模拟生成失败、恢复入口、质量状态、第一天学习及清单持久化。
