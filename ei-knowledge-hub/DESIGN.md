# 知径知识图鉴设计规范

视觉方向：采用 VibeHub 术语页的浅色知识图鉴结构，保留知径青色品牌。参考 Mintlify 的文档产品排版原则，但不复制其绿色品牌。

## 核心原则

1. 术语目录负责发现和筛选，独立详情页负责完整讲解。
2. 白色阅读面、冷灰背景、青色单一主强调色；靛蓝仅用于“用户原话”，玫红仅用于“易混边界”。
3. 深度主要来自留白、细边框和内容结构，不使用厚重阴影或大面积深色卡片。
4. 每种可视化表达一种真实关系，不把所有概念塞进同一种流程图。

## Design tokens

- 字体：`DM Sans`, `Segoe UI`, system-ui, sans-serif
- 页面背景：`#f8fafc`
- 内容表面：`#ffffff`
- 主文字：`#0f172a`
- 次文字：`#475569`
- 弱文字：`#94a3b8`
- 边框：`#e2e8f0`
- 品牌青：`#0891b2`
- 品牌浅底：`#ecfeff`
- 用户原话底：`#eef2ff`
- 易混边界底：`#fff1f2`
- 容器圆角：16px
- 内部卡片圆角：12px
- 按钮与筛选项：全圆角
- 间距基准：8px；常用 16 / 24 / 32 / 48px

## 页面结构

### 术语目录

- 最大内容宽度 1152px。
- 顶部为左对齐的图鉴说明，不做营销式居中 Hero。
- 搜索和模块筛选吸顶。
- 词条卡两列，移动端单列；卡片只预览口语问题、定义、模块、易混词和可视化类型。

### 术语详情

- 最大阅读宽度 1024px。
- 顺序固定：标题与别名 → 用户原话 → 工作定义 → 专属图解 → 完整例子 → 深入说明 → 易混对比 → 相关词。
- 每条只展示一个主可视化，避免页面变成组件展览。
- 上一个/下一个词放在页尾，保证连续学习。

## 可视化模板

- `flow`：连续动作和依赖链路。
- `loop`：最后一步明确回到第一步的反馈闭环。
- `anatomy`：一个整体由哪些部件组成。
- `roles`：参与方与各自动作的泳道式表达。
- `scenario`：事实卡、原话和场景步骤组合。
- `compare`：两个方案或概念的双列对比。
- `states`：状态与触发后的变化顺序。
- `layers`：从表层到底层的系统栈。
- `tree`：根节点和子层级。
- `timeline`：按时间或阶段演进。
- `matrix`：按两到四种条件归类判断。

## 交互与响应式

- 仅使用 150-200ms 的颜色、边框和轻微位移动效。
- 尊重 `prefers-reduced-motion`。
- 768px 以下，目录卡、对比、矩阵、状态图统一折为单列。
- 所有搜索框、按钮和链接保留清晰的键盘焦点状态。
