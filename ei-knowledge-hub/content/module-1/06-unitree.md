## PM 视角要点

深度研究一家公司，是产品经理的**「解剖课」**。宇树是国内具身智能领域最值得研究的案例之一，因为它同时具备：

- **可验证的产品**：多款量产 SKU，有真实售价和出货量
- **开放的技术栈**：SDK、仿真、开源模型，可实际体验
- **清晰的演进路径**：四足 → 人形，每一步都有商业逻辑
- **活跃的开发者社区**：GitHub 星标、论文引用、高校采用率高

### 今日研究方法

```
官网产品页 ──→ 技术参数与 SKU 策略
GitHub 仓库 ──→ 技术栈、开放程度、社区活跃度
招聘 JD ──→ 战略方向与能力缺口
论文/演示 ──→ 真实技术上限
用户评价 ──→ 交付体验与痛点
```

### 今日产出

一份 **宇树公司产品档案**（建议 1 页 A4），包含：公司概况、产品矩阵、技术路线、商业模式、优劣势、对行业的启示。

### 技术能力拆解

#### 运动控制（核心壁垒）

- 高动态运动：四足奔跑、后空翻、地形适应
- 底层自研：电机驱动、控制器、控制算法全栈
- 从四足到人形：关节模组、平衡控制技术复用

#### 感知与 AI

- 多模态传感：深度相机、激光雷达（部分型号）、IMU
- 语音交互：Go2 搭载 GPT 类能力（合作方案）
- 自主导航：SLAM、避障、跟随
- 开源模型：UnifoLM（宇树自研具身大模型）

#### 开发者生态

| 组件 | 内容 |
|------|------|
| SDK | unitree_sdk2（Python/C++），支持全产品线 |
| 仿真 | unitree_mujoco（MuJoCo 仿真环境） |
| ROS 支持 | unitree_ros2 包 |
| 开源模型 | github.com/unitreerobotics（多个仓库） |
| 文档 | 中英文开发者文档，示例丰富 |
| 社区 | GitHub Issues 活跃，高校实验室广泛采用 |

### 商业模式分析

```
收入来源
├── 硬件销售（主力）
│   ├── 消费级四足（走量，品牌传播）
│   ├── 行业四足（利润主力）
│   └── 人形（品牌制高点，未来增长）
├── 配件与维保
│   └── 电池、相机、维修服务
└── 潜在方向
    ├── 软件订阅（AI 能力增值服务）
    ├── 行业解决方案（巡检、物流打包方案）
    └── 开发者平台（模型市场、应用分成）
```

### SWOT 分析

| | 正面 | 负面 |
|---|------|------|
| **内部** | **S 优势** | **W 劣势** |
| | 运动控制全球领先 | 操作能力（抓取/精细操作）仍在发展 |
| | 极致性价比 | 品牌溢价低于 Boston Dynamics |
| | 开发者生态成熟 | 人形产品商业化尚早 |
| | 供应链垂直整合 | 大模型能力需持续投入 |
| **外部** | **O 机会** | **T 威胁** |
| | 具身智能政策利好 | 人形赛道竞争者涌入（智元等） |
| | 高校科研市场需求大 | 国际政策与出口限制 |
| | 四足巡检场景成熟 | 大厂（Tesla、Figure）降维竞争 |

### 对产品经理的启示

1. **先打透一个形态，再扩展**：四足成熟后再做人形，降低技术风险
2. **开发者生态是最便宜的 GTM**：让高校和开发者帮你验证场景、传播品牌
3. **SKU 分层策略**：消费级走量、行业级赚钱、旗舰级定品牌
4. **开源是信任建设**：核心控制不开源，但 SDK 和仿真开放，降低接入门槛
5. **参数表背后有工程取舍**：为什么 G1 比 H1 便宜？减少自由度、降低负载、简化传感

### 与竞品的关键差异

| 对比维度 | 宇树 | Boston Dynamics | 智元 |
|----------|------|-----------------|------|
| 售价 | 万元级 | 数十万美元 | 数十万元 |
| 开放程度 | 高（SDK+仿真+部分开源） | 低（封闭生态） | 中（建设中） |
| 运动能力 | 极强 | 极强 | 快速进步 |
| 操作能力 | 发展中 | 演示级（Atlas） | 重点投入 |
| 商业化 | 已规模化 | 行业客户为主 | 早期 |
