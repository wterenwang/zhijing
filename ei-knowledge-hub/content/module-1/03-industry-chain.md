## PM 视角要点

产业链认知直接决定产品经理的**日常工作的重心**：

- **你在哪一层，决定你的竞品是谁**：做整机的和做关节模组的，竞品名单完全不同
- **上下游关系决定合作策略**：需要集成谁的能力？哪些必须自研？
- **利润分布影响商业决策**：上游零部件毛利高但量大，下游场景贴近现金流
- **技术瓶颈在产业链上的位置**：当前行业瓶颈在「大脑」（算法/模型），不在「小脑」（运动控制）或「肢体」（硬件）

### 产品经理要回答的三个定位问题

1. 我们公司在产业链的哪一段？（上游 / 中游 / 下游）
2. 我们的核心资产是什么？（硬件设计 / 算法平台 / 场景数据 / 客户关系）
3. 我们的收入模式是什么？（卖硬件 / 卖软件授权 / 卖服务 / 平台抽成）

## 核心概念

### 具身智能产业链三层结构

```
┌─────────────────────────────────────────────────────────┐
│                    下游：场景应用                          │
│  家庭服务 / 工业巡检 / 物流搬运 / 医疗康复 / 教育科研       │
│  代表：场景方案商、系统集成商、垂直 SaaS                    │
├─────────────────────────────────────────────────────────┤
│                    中游：整机与平台                        │
│  人形机器人 / 四足机器人 / 协作机械臂 / 开发者平台 / SDK    │
│  代表：宇树、优必选、智元、Figure、Tesla Optimus          │
├─────────────────────────────────────────────────────────┤
│                    上游：核心零部件与基础技术                │
│  关节模组 / 减速器 / 伺服电机 / 传感器 / 芯片 / 仿真平台    │
│  代表：绿的谐波、汇川技术、奥比中光、英伟达 Isaac           │
└─────────────────────────────────────────────────────────┘
```

### 上游：核心零部件与基础技术

| 品类 | 关键能力 | 代表厂商 | 产品影响 |
|------|----------|----------|----------|
| 减速器 | 扭矩传递、精度 | 绿的谐波、哈默纳科 | 决定关节力度与寿命 |
| 伺服电机 | 高响应驱动 | 汇川、松下、Maxon | 决定运动速度与精度 |
| 关节模组 | 一体化关节 | 本末科技、意优科技 | 降低整机集成难度 |
| 传感器 | 力觉、视觉、IMU | 奥比中光、Velodyne | 决定感知能力上限 |
| 计算芯片 | 边缘 AI 推理 | 英伟达 Jetson、地平线 | 决定端侧模型部署能力 |
| 仿真平台 | Sim-to-Real | NVIDIA Isaac Sim、MuJoCo | 降低真机调试成本 |

**上游 PM 关注点**：规格参数、成本曲线、供货周期、国产化替代进度

### 中游：整机与平台

| 品类 | 核心能力 | 商业模式 | 关键指标 |
|------|----------|----------|----------|
| 人形机器人 | 通用形态、场景泛化 | 硬件销售 + 软件订阅 | 自由度、续航、成本 |
| 四足/轮足机器人 | 高动态移动、巡检 | 硬件销售 + 行业方案 | 负载、地形适应、IP 等级 |
| 协作机械臂 | 精密操作、安全协作 | 硬件销售 | 重复定位精度、负载比 |
| 开发者平台 | SDK、仿真、模型 | 生态授权、云服务 | 开发者数量、应用数量 |

**中游 PM 关注点**：产品定义、技术路线、生态建设、SKU 策略

### 下游：场景应用

| 场景 | 典型任务 | 付费方 | 成熟度 |
|------|----------|--------|--------|
| 工业巡检 | 设备巡检、异常检测 | 工厂业主 | 较高 |
| 物流仓储 | 搬运、分拣、码垛 | 物流企业 | 中等 |
| 家庭服务 | 清洁、陪伴、辅助 | 消费者 | 早期 |
| 教育科研 | 教学、算法验证 | 高校/实验室 | 成熟 |
| 特种作业 | 消防、救援、军工 | 政府/企业 | 定制为主 |

**下游 PM 关注点**：场景 ROI、部署流程、客户成功、合规与安全

### 价值流向与当前瓶颈

```
上游零部件 ──供应──→ 中游整机 ──交付──→ 下游场景
     ↑                    ↑                  ↑
  成本竞争            技术+品牌竞争        场景+数据竞争
  规模效应            生态壁垒            客户粘性

当前行业瓶颈：中游的「认知大脑」（VLA / 世界模型 / 长程规划）
              下游的「场景数据闭环」（真实交互数据规模不足）
```

### 国产化与供应链观察

| 环节 | 国产化程度 | 趋势 |
|------|------------|------|
| 减速器 | 中等，谐波已突破 | 成本持续下降 |
| 伺服系统 | 较高 | 汇川等已具备竞争力 |
| 视觉传感 | 较高 | 奥比中光等量产成熟 |
| 高算力芯片 | 较低 | 依赖英伟达，国产替代进行中 |
| 整机集成 | 高 | 国内厂商全球领先（四足领域） |
| 基础大模型 | 中等 | 开源模型缩小差距，端侧部署仍挑战 |
