# 家庭场景聚焦：清洁 vs 厨房

场景选择是家庭机器人产品成败的第一步。本章节对比「地面清洁 + 物品整理」与「厨房辅助」两大方向，从用户需求、技术成熟度、安全合规与商业空间四个维度做结构化取舍。

## PM视角要点

- **清洁整理场景**：市场教育已完成，用户知道扫地机是什么；痛点集中在漏扫、缠绕、无法处理散落物品、多楼层/多房间协同。升级方向是「扫 + 整」一体化。
- **厨房场景**：频次高、痛点强（备餐、洗碗、收纳），但涉及刀具、明火、液体、食物安全，监管与责任边界复杂，适合作为 2.0 愿景而非首期 MVP。
- 用用户旅程地图标注情绪曲线：扫地机在「被困」「漏扫」「找不到基站」等节点的挫败感是产品机会窗口。
- 问题陈述（Problem Statement）模板：「[用户] 在 [场景] 下需要 [任务]，但现有方案因为 [根因] 导致 [不良后果]。」
- 输出物：场景决策备忘录 + 一句话问题定义 + 约束条件清单（成本上限、安全等级、隐私要求）。

## 核心概念

| 概念 | 说明 |
|------|------|
| 地面清洁 + 物品整理 | 在扫地/拖地基础上增加识别、抓取、归位等操作能力，覆盖客厅、卧室等开阔区域 |
| 厨房辅助 | 台面整理、简易备餐协助、餐具收纳等，对精细操作与安全要求更高 |
| 用户旅程地图 | 从触发需求到任务完成的全触点可视化，含情绪与机会点 |
| 技术成熟度曲线 | 评估感知、规划、操作各模块在目标场景下的商用就绪程度 |
| 约束三角 | 成本、安全、性能三者不可同时极致，PM 负责划定可行域 |

### 场景对比简表

| 维度 | 清洁 + 整理 | 厨房辅助 |
|------|-------------|----------|
| 市场规模 | 大，品类成熟 | 中，尚早 |
| 技术难度 | 中（导航成熟，抓取在进步） | 高（精细操作 + 安全） |
| 用户付费意愿 | 已验证，愿为省心付费 | 高潜力，但需强信任 |
| 监管风险 | 低 | 中高（食品安全、人身伤害） |
| 适合 MVP | 是 | 更适合长期路线图 |

### 推荐聚焦路径（学习项目）

优先选择 **「客厅/卧室地面清洁 + 轻量物品归位」** 作为 MVP：复用成熟导航栈，用 VLA 解决「散落袜子、玩具、拖鞋」等高频小物件整理，故事完整且风险可控。
