# VLA 家庭抓取方案

当痛点指向「扫而不整」时，VLA（Vision-Language-Action）模型提供了从视觉理解到动作执行的统一路径。本章节帮助 PM 理解 VLA 在家庭抓取场景的能力边界、选型考量与产品化要点，无需推导公式，但要能讲清 trade-off。

## PM视角要点

- VLA 的核心价值是 **语义级操作**：用户说「把沙发上的抱枕放到收纳篮」，系统需理解物体、空间关系并生成动作序列，而非预编程固定轨迹。
- 家庭场景难点：光照变化、透明/反光物体、杂乱堆叠、软体物品形变、人机混处安全距离。
- PM 应关注 **成功率、泛化性、延迟、算力成本** 四元组，而非仅看论文 SOTA 数字（实验室环境与真实家庭差距大）。
- 机械臂方案需权衡：固定臂（桌面/柜面）vs 移动底盘 + 臂（整机协调难）vs 纯夹爪升降（成本低但能力有限）。
- 输出物：技术可行性评估报告 + 推荐方案 + 对产品功能定义的影响说明。

## 核心概念

| 概念 | 说明 |
|------|------|
| VLA 模型 | 将视觉输入与自然语言指令联合编码，直接输出机器人动作 token 或轨迹的统一架构 |
| RT-1 / RT-2 | Google Robotics Transformer 系列，大规模机器人数据预训练的代表工作 |
| OpenVLA | 开源 VLA 实现，便于评估部署成本与社区生态 |
| 泛化（Generalization） | 模型在训练分布外的新物体、新布局、新指令上的表现 |
| Sim-to-Real | 仿真环境训练迁移到真实机器人，可降低数据采集成本但存在域差距 |

### 家庭抓取产品化关键指标

| 指标 | 说明 | MVP 参考目标（示例） |
|------|------|----------------------|
| 抓取成功率 | 单次 pick 成功完成的比例 | ≥ 85%（限定物体集） |
| 指令理解准确率 | 语言指令与意图匹配正确率 | ≥ 90%（核心指令集） |
| 端到端延迟 | 从指令下达到动作开始 | ≤ 3 秒 |
| 支持物体类别 | 可可靠抓取的物体类型数 | 首期 10 至 15 类常见家居小物 |
| 安全停距 | 与人/宠物最小安全距离 | 符合 ISO 13482 相关条款 |

### 技术路线对比

| 路线 | 优点 | 缺点 | 产品阶段 |
|------|------|------|----------|
| 端到端 VLA | 语义理解强，少手工规则 | 数据需求大，可解释性弱 | 中长期主力 |
| 感知 + 传统规划 | 可控、可调试 | 泛化差，规则维护成本高 | 短期 MVP 可混合 |
| 遥操作数据采集 + 模仿学习 | 快速积累家庭数据 | 隐私与规模受限 | 冷启动补充 |
