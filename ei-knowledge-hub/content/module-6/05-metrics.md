# 体验评估指标：成功率、延迟与满意度

产品方案是否「更好」，必须用可量化、可追踪的指标说话。本章节为家庭场景机器人定义核心体验指标、测试方案与基准/目标值，连接 PRD 验收标准与面试中的数据叙事。

## PM视角要点

- **任务成功率**是家庭操作类产品的北极星之一，但必须定义清楚任务边界（哪些物体、哪些房间、什么光照条件）。
- **延迟**影响主观体验：超过 3 秒无反馈，用户会以为设备死机；端到端延迟需拆分感知、推理、规划、执行各段定位瓶颈。
- **满意度**不能只看 NPS。建议组合 CSAT（单次任务）、SEQ（单题易用性）、重试率、人工介入率等行为指标。
- A/B 测试在家庭机器人场景难做大规模，可用 **对照实验**（旧版 vs 新版）、**日记研究**、**实验室可用性测试** 替代。
- 输出物：评估指标体系文档 + 测试方案 + 基准值与目标值表。

## 核心概念

| 概念 | 说明 |
|------|------|
| 任务成功率（Task Success Rate） | 在定义条件下，任务无需人工介入完成的比例 |
| 端到端延迟（E2E Latency） | 从用户触发到机器人开始有效动作的时间 |
| 人工介入率 | 任务过程中用户不得不手动帮助（解救、重新摆放）的比例 |
| CSAT | Customer Satisfaction，通常 1 至 5 分，针对单次交互 |
| 统计显著性 | A/B 测试中判断差异是否由随机波动导致，常用 p < 0.05 |

### 核心指标定义表

| 指标 | 定义 | 采集方式 | MVP 目标（示例） |
|------|------|----------|------------------|
| 清扫覆盖率 | 实际清扫面积 / 应扫面积 | 地图日志 | ≥ 95% |
| 物品归位成功率 | 成功归位次数 / 尝试次数 | 视觉确认 + 用户确认 | ≥ 80% |
| 语音指令识别率 | 正确理解意图 / 总指令数 | 日志 + 抽样人工标注 | ≥ 92% |
| 指令响应延迟 P95 | 95% 指令的响应时间 | 端侧埋点 | ≤ 2.5 秒 |
| 卡住率 | 需人工解救次数 / 任务数 | 故障日志 | ≤ 5% |
| 任务满意度 CSAT | 任务后 1 至 5 分评价 | APP 弹窗 | 均值 ≥ 4.0 |

### 测试方案要点

1. **样本设计**：至少 15 至 20 户家庭，覆盖不同户型、地面材质、是否有宠物/儿童
2. **任务脚本**：标准化任务清单（如「清理客厅散落 5 件物品」），减少操作差异
3. **对照组**：当前市售扫地机 vs 你的方案原型/概念验证
4. **观察记录**：视频 + 问卷 + 访谈三板斧，捕捉量化指标解释不了的细节
5. **时间节点**：开发中期可用性测试（找大问题）、发布前验收测试（对目标值）

### 指标与产品决策联动

- 成功率低 + 延迟高 → 优先优化模型推理或缩小物体支持范围
- 满意度低但成功率高 → 交互反馈或噪音/外观等体验问题
- 卡住率高 → 导航/避障模块优先于抓取能力扩展
