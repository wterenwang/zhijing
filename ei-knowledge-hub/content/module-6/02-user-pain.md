# 用户痛点分析：扫地机器人品类

即便在成熟的扫地机器人市场，用户不满依然普遍。本章节系统梳理真实用户反馈，将痛点归类、排序，并映射到产品功能机会，为后续 VLA 与交互设计提供依据。

## PM视角要点

- 痛点调研渠道：电商差评（京东/天猫）、小红书/知乎吐槽帖、Reddit r/RobotVacuums、朋友访谈。至少收集 10 条可溯源的真实反馈。
- 区分「硬件痛点」（吸力、续航、噪音）与「智能痛点」（漏扫、误识别、无法处理复杂物品）。具身智能 PM 应聚焦后者。
- 用户对「人形机器人进家」的期望与顾虑并存：期望它能「像人一样整理」，顾虑隐私、安全、价格与可靠性。
- 痛点归类后用 **频率 × 严重程度** 矩阵找 TOP 3，避免被小众但激烈的抱怨带偏。
- 输出物：痛点清单 + TOP 3 根因分析 + 痛点-机会映射矩阵。

## 核心概念

| 概念 | 说明 |
|------|------|
| 漏扫与重复扫 | 路径规划或地图构建缺陷导致覆盖不全或效率低下 |
| 缠绕与卡住 | 线缆、地毯流苏、椅腿等导致停机，需人工解救 |
| 无法处理散落物 | 扫地机只能绕开袜子/玩具，无法捡起归位，是「扫而不整」的核心缺口 |
| 多楼层/多房间协同 | 换楼层需搬运基站、多地图切换体验差 |
| 隐私顾虑 | 带摄像头的移动设备引发「是否在监控」的信任问题 |

### 典型用户吐槽（调研方向）

1. 「每次扫完客厅，孩子的乐高还是满地都是，还得我亲手捡。」
2. 「经常卡在餐椅腿中间，APP 报警了我人不在家。」
3. 「说是智能避障，拖鞋和电线还是会被卷进去。」
4. 「人形机器人要是能帮我收拾茶几就好了，但怕它摔坏东西。」
5. 「摄像头扫地机我都不敢开，怕数据上传。」

### 痛点根因与机会映射

| 痛点 | 可能根因 | 产品机会 |
|------|----------|----------|
| 散落物无法处理 | 无操作臂/抓取能力，仅 2D 避障 | VLA 轻量抓取 + 归位 |
| 频繁卡住 | 3D 感知不足，椅腿等细障碍物建模差 | 智能避障升级 + 脱困策略 |
| 漏扫 | 地图更新慢，动态障碍物处理差 | 实时语义地图 + 补扫逻辑 |
| 隐私担忧 | 视频上云默认开启 | 本地处理 + 明确指示灯与权限 |
