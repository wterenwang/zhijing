# 核心硬件认知

## PM视角要点

- 硬件决定产品天花板：同样的算法，在不同关节精度、减速比、相机分辨率下，体验差异巨大。
- 产品经理不必会画电路图，但要能读懂 BOM 级取舍：成本、重量、续航、可靠性之间的三角关系。
- 选型问题要具体：「为什么用谐波减速器而非行星减速器？」「为什么头部放 RGB-D 而非纯 RGB？」
- 与供应链和研发对齐时，用「性能指标 + 场景约束」沟通，而非抽象地说「要更好」。

## 核心概念

### 关节（Joint）

- **自由度（DoF）**：决定动作空间维度，直接影响抓取、行走、操作灵巧度
- **减速器**：谐波（精度高、成本高）、行星（成本低、背隙大）
- **编码器**：绝对式/增量式，影响上电归零与定位精度

### 伺服系统（Servo）

- 电机 + 驱动器 + 编码器 + 控制算法闭环
- 关键参数：额定扭矩、峰值扭矩、带宽、温升
- PM 关注：同样动作下是否过热降频、是否出现可感知的「力矩饱和」

### IMU（惯性测量单元）

- 测量角速度、加速度，辅助姿态估计与步态平衡
- 消费级 vs 工业级 IMU 在漂移、噪声、标定上差异明显
- 产品场景：快速转身、上下楼梯时，IMU 质量直接影响「稳不稳」的主观感受

### 深度相机（Depth Camera）

- 提供 RGB + 深度，支撑抓取、避障、SLAM
- 常见方案：结构光、ToF、双目立体
- 限制：强光、透明/反光物体、远距离精度下降
