# 大脑与小脑协同

## PM视角要点

- 机器人「大脑」负责理解意图、规划任务、调用工具；「小脑」负责毫秒级平衡、轨迹跟踪、力控与 reflex。产品功能应明确落在哪一层。
- 用户说「帮我把杯子拿来」，大脑做语义理解与任务分解，小脑保证抓取过程中不洒、不撞、不掉。
- 常见产品失误：把大模型对话能力等同于机器人执行力，忽略小脑层稳定性与硬件极限。
- 评估指标要分层：大脑看任务理解准确率、规划成功率；小脑看控制频率、抖动、碰撞率、能耗。

## 核心概念

### 大脑层（认知与规划）

- **输入**：自然语言、视觉语义、环境地图、用户偏好
- **输出**：子任务序列、技能调用、异常恢复策略
- **典型组件**：VLA、LLM Agent、任务规划器、记忆与 RAG

### 小脑层（运动与控制）

- **输入**：关节状态、IMU、力矩、触觉反馈
- **输出**：关节目标位置/速度/力矩、步态参数
- **典型组件**：PD 控制、MPC、RL 策略、阻抗控制

### 协同模式

```
用户指令 → 大脑（理解+规划）→ 技能接口 → 小脑（执行+反馈）→ 感知回传 → 大脑（重规划）
```

产品经理需要定义「技能接口」：每个可调用技能的标准输入、输出、失败码与超时策略。
