# 第一阶段复盘

## PM视角要点

- Day 27-30 是 30 天学习阶段的收官：整合 Module 1-4 认知，识别 gap，规划 Module 5 项目实战。
- 复盘不是「学了多少页」，而是「能否交付可展示的产物」：竞品报告、交互方案、技术 story、知识图谱。
- 建议用 2 天时间做自测答辩：模拟面试，讲 3 个话题各 10 分钟，录音复盘。
- 诚实标注 weak points，作为 Module 5-7 的输入，而非回避。

## 核心概念

### 30 天能力自检清单

**行业与市场（Module 1）**

- [ ] 能定义具身智能并区分与 AGI、自动化差异
- [ ] 能画出产业链上下游
- [ ] 能列举 3 家头部公司及其差异化

**技术基础（Module 2-3）**

- [ ] 能解释大脑/小脑分层
- [ ] 能对比 VLA / RL / IL 适用场景
- [ ] 能描述数据闭环六步
- [ ] 能输出成本/性能/可靠性取舍分析

**专项深度（Module 4）**

- [ ] 能讲解「把杯子拿来」VLA pipeline
- [ ] 能说明 Diffusion Policy vs ACT 选型
- [ ] 能介绍宇树 RL Train→Sim2Real 流程
- [ ] 能结构化速读 1 篇 robotics 论文

### 复盘输出物

1. **个人知识图谱更新**：补全 weak nodes
2. **作品集素材包**：竞品报告 + 交互 storyboard + 1 个 tech case 幻灯片
3. **Gap 清单**：按优先级排列下一阶段补强项
4. **Module 5 预习**：开发者生态项目用户画像草稿

### 自测答辩三题

1. 为什么选择 VLA 而不是传统 pipeline 做家庭抓取？
2. 你的目标产品数据飞轮如何冷启动？
3. 宇树 G1 与 Figure 02 的 product positioning 差异是什么？

### 下一阶段预告

Module 5 进入「项目一：开发者生态」，将综合运用用户调研、SDK 竞品、PRD 与商业模式设计。第一阶段的技术认知是 PRD 可信度的基础。
