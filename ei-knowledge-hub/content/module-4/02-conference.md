# 顶会论文追踪

## PM视角要点

- 机器人领域顶会是技术风向标的「早刊」：CoRL 偏学习与控制，ICRA 覆盖更广的工程与系统。
- PM 读论文的目标：判断 6-18 个月内哪些能力可能进入产品，而非复现每一个公式。
- 建立个人论文 RSS：按关键词（VLA、manipulation、locomotion、sim2real）订阅 arXiv + 顶会 proceedings。
- 读论文要输出「So What」：对用户价值、竞品差距、roadmap 的影响各一句话。

## 核心概念

### CoRL（Conference on Robot Learning）

- 专注机器人学习：RL、IL、VLA、世界模型等
- 论文质量高、与产业结合紧，适合 PM 跟踪 manipulation 与 foundation model 方向
- 每年 12 月左右，官网发布 accepted papers 与 videos

### ICRA（IEEE International Conference on Robotics and Automation）

- 机器人领域规模最大综合会议之一
- 覆盖感知、规划、控制、医疗机器人、自动驾驶等
- 适合了解系统工程、硬件创新与非学习类 baseline

### PM 论文追踪工作流

```
1. 浏览 accepted list / arXiv daily
2. 筛 title + abstract（5 分钟/篇）
3. 深读 2-3 篇/周（figure + experiment）
4. 写卡片：问题、方法、指标、局限、产品 implication
5. 月度汇总分享给团队
```

### 高价值关键词

- Vision-Language-Action, Diffusion Policy, World Model
- Sim-to-Real, Domain Randomization, Teleoperation
- Bimanual Manipulation, Mobile Manipulation
