# 模块总览：产品与技术基础（下）

## PM视角要点

- 第3周从「懂技术」转向「做产品」：在成本、性能、可靠性之间做取舍，设计人机交互，构建数据飞轮，输出竞品分析报告。
- 本周产出应可直接用于作品集：一份家庭机器人交互方案草图、一份数据飞轮 diagram、一份结构化竞品报告。
- 产品经理的价值在于把技术可能性翻译成用户可感知、可付费、可迭代的体验。
- Day 18-20 集中完成竞品报告，需回溯第1周竞品章节与第2周技术认知。
