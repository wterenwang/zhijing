# 冲刺总览：作品集整合与面试准备

90 天学习的最后 8 天（第 83 至 90 天）是收官冲刺：将两个实战项目整合为统一作品集，打磨面试问答，更新简历并开始投递。本阶段不再追求新知识输入，而是把已有产出转化为 **可讲述、可展示、可拿到 offer** 的求职资产。

## PM视角要点

- 作品集不是文档堆砌，而是 **能力证明**：用户洞察、方案设计、技术理解、商业思维、表达与复盘，五个维度都要在 20 分钟内可被验证。
- 两个项目应形成叙事互补：项目一（开发者生态）证明 B 端/平台能力；项目二（家庭场景）证明 C 端体验与 AI 产品化能力。
- 面试准备分三层：自我介绍（who）、项目深挖（what/how/why）、行业认知（where is embodied AI going）。
- 第 89 天「最终复盘」是刻意留白：通览笔记与费曼复述，修补知识体系漏洞，写下对岗位的终极理解。
- 投递不是最后一天才做。第 90 天是启动日，清单应提前备好，边投边根据反馈迭代简历与作品集。

## 核心概念

| 概念 | 说明 |
|------|------|
| 作品集整合 | 统一视觉、串联叙事、导出可分享 PDF/PPT 的完整求职材料 |
| STAR 法则 | Situation, Task, Action, Result，结构化回答行为面试题 |
| Trade-off 叙事 | 主动讲述「在 A 与 B 之间为何选 B」，展示 PM 判断力 |
| 目标公司清单 | 按赛道（整机/零部件/AI 算法/平台）与优先级排列的投递列表 |
| 费曼复述 | 用简单语言向他人解释所学，检验是否真正理解 |
