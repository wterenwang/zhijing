# 投递简历与申请策略

最后一天的学习任务是启动求职：更新简历、列出目标公司、开始投递。本章节提供具身智能 PM 岗位的简历写法、公司调研框架与投递节奏建议。

## PM视角要点

- 简历不是作品集缩写。1 页纸内突出 **与岗位最相关的 3 段经历/项目**，作品集链接放显眼位置（GitHub Pages、Notion、PDF 网盘均可）。
- 项目描述用 **动作动词 + 量化结果**：「主导 2 类用户访谈，定义 SDK MVP 12 项 P0 功能，设计技能商店分成模型」优于「参与开发者生态项目」。
- 目标公司分层：A 档（梦想公司，精心定制简历）、B 档（匹配度高，标准简历）、C 档（练手面积试，快速投递）。
- 秋招与可转正实习并行投递，注意各公司流程时间节点（提前批、正式批、补录）。
- 第 89 天复盘产出的「对具身智能 PM 岗位的最终理解」，应反哺简历 Summary 和求职信（Cover Letter）。

## 核心概念

| 概念 | 说明 |
|------|------|
| ATS 友好简历 | 避免复杂排版，关键词与 JD 对齐，便于招聘系统解析 |
| 作品集链接 | 简历中可点击的 URL，确保 90 天内有效、移动端可开 |
| JD 关键词映射 | 将岗位要求（用户研究、PRD、数据驱动、AI 产品）映射到你的项目 bullet |
| 内推 | 通过校友、社群、LinkedIn 触达招聘方，显著提高回复率 |
| 投递追踪表 | 记录公司、岗位、日期、状态、反馈，避免混乱与遗漏 |

### 简历结构建议（具身智能 PM）

1. **Header**：姓名 | 手机 | 邮箱 | 作品集链接 | 城市
2. **Summary**（2 至 3 行）：具身智能/机器人产品方向 + 核心能力标签 + 90 天系统学习与 2 个实战项目
3. **项目经历**（重点）
   - 开发者生态 SDK 产品设计 | 个人项目 | 2025.XX
   - 家庭场景 VLA 功能优化 | 个人项目 | 2025.XX
4. **工作/实习经历**（如有，按相关性排序）
5. **教育背景**
6. **技能**：用户研究、PRD、Figma、数据分析、Python 基础、ROS 2 概念、LLM/VLA 产品化理解

### 目标公司调研维度

| 维度 | 调研问题 |
|------|----------|
| 赛道 | 整机 / 关节电机 / 感知 / 具身大模型 / 垂直场景 |
| 产品阶段 | 概念验证 / 小批量 / 规模化商用 |
| 团队背景 | 学术派 / 工程派 / 互联网跨界 |
| 岗位定位 | 偏硬件 PM / 偏软件平台 / 偏 AI 算法产品化 |
| 近期动态 | 融资、新品发布、开源项目、顶会论文 |

### 投递节奏（建议）

- **第 89 天**：完成简历终稿 + 公司清单 30 家 + 作品集最终版
- **第 90 天**：投递 A 档 5 家 + B 档 10 家，激活内推渠道
- **之后每周**：新增 10 至 15 家，根据面试反馈迭代简历与答案库
- **每次面试后 24 小时内**：发送感谢信，记录追问题并更新答案库
